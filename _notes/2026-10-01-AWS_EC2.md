### Types of EC2 Instances

- **C type**: Compute optimized (game servers, machine learning)
- **R type**: Memory optimized (databases, web cache stores)
- **X type**: Extreme memory optimized (in-memory databases)

### EC2 purchasing options

A few purchase options are available in AWS. 

![alt text](https://arizzi-alexandre.github.io/arizzi-alexandre.gitub.io/assets/image.png)
- On demand(Written instances), full price per hour, short, good for tests
- Reserved, Good discount, with a reservation period, predictable workload
- Saving plans Same than reserved, but you can change instance size,region..
- Spot instances, unsold, up to 90%. You indicate a price you want to pay, As long as the instance price is under, you keep it, once it"s aboce, you lose it. Its demand vs offer. The reason to use this is for eg: batch jobs or workloads resilient to failures. There are 2 spot request types
    - One-time:
    - Persitent
