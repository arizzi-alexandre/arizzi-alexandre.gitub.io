## High availbility for AWS.
- Vertical scaling = Increase size of the instance
- Honrizontal scaling = Increase number of instances, auto scaling group, load balancer
- High availability = Auto scaling group in multiple AZ.

## ELB AWS

### Elastic load balancer
Several kind of load balancer. 
1. Application load balancer: HTTP/HTTPS, Websocket
2. Network load balancer TCP, TLS, UDP
3. Gateway load balancer

Some load balancer can be setted as private or private

### Application load balancer
Layer 7 load balancer(HTTP)

We can route to different application depending on the URL, hostname in URL.. Great use for containerisation.
It has a port mapping feature.

### Network load balancer

### Gatewa load balancer
Used to reploy firewall apliance, IDS..


### Sticky sessions
Offer the possibility for a client to connect always to the same EC2. Works with load balancer and sert a cookie.
2 types of cookie:
- Application based cookie. Cookie generated by the application
- Duration-based cookie: Generated by the load balancer., Between 1 second and 7 days.

You can  configure the cookie in the target group.
What if the instance is replaced by the auto scaling group? -> We have to externalize the session(ElastiCache/DynamoDB)

### Cross zone load balancing
My load balancer will ditribute the traffic between instances in different regions. Is enabled at target group level.
