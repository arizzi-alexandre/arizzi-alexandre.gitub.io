## High availbility for AWS.
- Vertical scaling = Increase size of the instance
- Honrizontal scaling = Increase number of instances, auto scaling group, load balancer
- High availability = Auto scaling group in multiple AZ.

## ELB AWS

### Elastic load balancer
Several kind of load balancer. 
1. Application load balancer: HTTP/HTTPS, Websocket
2. Network load balancer TCP, TLS, UDP
3. Gateway load balancer

Some load balancer can be setted as private or private

### Application load balancer
Layer 7 load balancer(HTTP)

We can route to different application depending on the URL, hostname in URL.. Great use for containerisation.
It has a port mapping feature.
