## IAM Permissions

- IAM is a global service


### IAM Policy structure keywords

- Principal  = TO who is applied the Policy
- Action = List of actions that policy allows or deny
- Ressource = List of ressources the actions applie to



### MFA opstions
- Virtual MFA device(app on the phone)
- 2nd factor security key(Yubikey)
- Harware key(code displayed on the screen)

### Access key.
Access keys are assigned on users. THey allow for example to use AWS CLI from our laptop, as the user we created the access key.
They are composed of
- Access ID
- Secret access key

### AWS role

The best analogy so far, is a room cleaner in a hotel. He needs access cards that let him access to different room while he is doing his shift. This is the role of AWS role.

> 💡 **Exemple**
> Une application EC2 lit des photos dans S3 grâce au rôle `app-s3-reader`, sans clé dans le code.
